# Agentsflix — Binge-Worthy Micro Dramas

Agentsflix is the premier streaming platform for bite-sized dramas. Watch, create, and monetize 60-second micro-dramas on mobile.

- 🌐 Live site: [agentsflix.com](https://agentsflix.com)
- 📱 Platforms: iOS, Android, Web
- 🎬 Genres: Romance, Thriller, Fantasy, Comedy, Historical, Drama
- 🚀 Launching: August 2026

## Tech Stack

- Pure HTML / CSS / JavaScript
- No build tools required
- Dark cinematic theme (Netflix-style)
- Mobile-first vertical design

## Local Development

Simply open `index.html` in a browser. No build step needed.

```bash
# Optional: serve locally
npx serve .
```
