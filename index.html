Drop-in

Change one line. Keep your code.

AgentsFlix is OpenAI-API-compatible. If you have an OpenAI client, you have an AgentsFlix client. Same for Anthropic and Google formats.

  • Works with the official OpenAI, Anthropic, and LangChain SDKs
  • Streaming, tool calls, vision, and JSON mode supported
  • Per-request overrides for model, team, and budget
app.py 
// Before
from openai import OpenAI
client = OpenAI(api_key="sk-...")

// After — same SDK, smart routing on
from openai import OpenAI
client = OpenAI(
    base_url="https://api.agentsflix.com/v1",
    api_key="af-...",
)

resp = client.chat.completions.create(
    model="auto",   # let us pick the cheapest capable model
    messages=[{"role": "user", "content": "Summarize this PDF"}],
    extra_headers={"x-af-team": "marketing"},
)

FAQ

Questions, answered.

How is this different from a vanilla AI gateway like LiteLLM?

Open-source proxies handle routing. AgentsFlix adds the governance, policy, semantic cache, observability, and audit pieces enterprises actually need — and we run it for you with a 99.99% SLA. If you'd rather self-host, you can.

Do you store our prompts and responses?

Only what you tell us to. Audit logs default to redacted previews; full payloads are opt-in and stored in your region, encrypted with your KMS keys. Enterprise plans support BYO-bucket so the raw data never leaves your account.

How much does smart routing actually save?

For typical enterprise workloads — mixed support, marketing, and code tasks — we see 40–70% reduction in spend in the first 30 days. The bulk comes from semantic caching of duplicate prompts and routing easy tasks to small models.

Will my latency get worse?

Gateway overhead is sub-25ms p95 globally. Cache hits return in under 50ms — typically faster than any model. We run in five regions with automatic failover.

Do I have to change my code?

One line: swap the base_url. We're OpenAI-API-compatible, and we translate to Anthropic and Google formats server-side. Your existing SDKs, retries, and streaming logic keep working.

What's your security posture?

SOC 2 Type II is in progress (expected Q3). TLS 1.3 end-to-end, AES-256 at rest, region-pinned data residency, SSO/SCIM on all plans, and a self-host option for regulated industries.
